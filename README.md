# LMS
Library Management System :

This project is a simple Library Management System developed in C++ using Object-Oriented Programming (OOP) concepts.

The system allows users to:

1. Add new books
2. Display all books
3. Search books by title
4. Search books by author
5. Issue books to members
6. Return issued books
7. Store issuer/member details


✔Technologies Used:

C++, 
 Object-Oriented Programming (Classes & Objects),
 Arrays,
 Functions,
 String Handling using <cstring>.

 ✔Concepts Used:
 
Classes and Objects,
 Encapsulation,
 Arrays of Objects,
 Conditional Statements,
 Loops,
 Functions,
 Character,
 Arrays.

 »This project is console-based and does not use file handling. All data is stored temporarily during program execution.
